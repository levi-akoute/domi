Louer en sécurité

4 réflexes avant de payer

1. Visitez

Ne versez jamais d’argent avant d’avoir vu le logement de vos propres yeux.

2. Vérifiez

Assurez-vous que l’annonceur détient bien le bien. Privilégiez les profils vérifiés.

3. Exigez un reçu

Tout paiement doit être documenté par écrit, avec le nom du bénéficiaire.

4. Protégez vos codes

Ne communiquez jamais un code Mobile Money ou un code confidentiel.
